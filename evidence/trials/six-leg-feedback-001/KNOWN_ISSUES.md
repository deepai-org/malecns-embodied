# Flawed initial body prototype

The first six-leg generator retained the source `floor` and added a second
coplanar `experiment_floor`. This changes contact mechanics. The run is retained
as a construction failure, not accepted evidence of support or behavior.

Its command/transduction verification remains valid within that flawed scene.
Muscle activation/integration states were not recorded, so complete physical
state replay is also unavailable. The corrected generator must reuse the
original floor and produce a fresh scene/trial, not overwrite this evidence.

Rendering initially failed because the host lacked EGL/OpenGL loader libraries.
Installing Ubuntu `libegl1` and `libopengl0` enabled rendering without modifying
neural or muscle parameters. The rendered pose is from this flawed trial and
must not be presented as the corrected experiment.
